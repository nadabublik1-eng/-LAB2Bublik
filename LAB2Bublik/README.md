# Лабораторна робота №2

Тема
Проєктування та реалізація об'єктно-орієнтованих систем у Python з використанням класів і спадковості.

Мета роботи
Набути практичних навичок об'єктно-орієнтованого програмування мовою Python, навчитися працювати з класами, наслідуванням, інкапсуляцією, поліморфізмом, абстрактними класами та патернами проєктування.

Виконані завдання

Завдання 1. Наслідування та поліморфізм**
- Створено базовий клас та три підкласи.
- Реалізовано перевизначення методів.
- Продемонстровано поліморфізм.

Завдання 2. Інкапсуляція**
- Реалізовано приватні та захищені атрибути.
- Використано декоратор `@property`.
- Додано перевірку коректності значень.

Завдання 3. Магічні методи
- Реалізовано магічні методи Python.
- Продемонстровано перевантаження операторів.
- Реалізовано арифметичні операції та порівняння об'єктів

Завдання 4. Абстрактні класи та композиція
- Створено абстрактний базовий клас.
- Реалізовано конкретні підкласи.
- Продемонстровано композицію об'єктів.

Завдання 5. Патерн Strategy
- Реалізовано патерн проєктування Strategy.
- Продемонстровано взаємодію класів.
- Показано можливість розширення системи.

 Використані технології
- Python 3
- Об'єктно-орієнтоване програмування (ООП)
- Стандартна бібліотека Python

Запуск програми

Для запуску окремого завдання виконайте команду:

```bash
python zavdannya_1.py
```

Аналогічно запускаються файли `zavdannya_2.py`  `zavdannya_5.py`.
